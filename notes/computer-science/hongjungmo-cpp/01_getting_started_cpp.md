## 프로그래밍 언어란
* c++는 프로그래밍 언어의 하나이다.
* 프로그램 / 애플리케이션 / 소프트웨어 / 하드웨어
* 키워드
	* 기계어: 컴퓨터는 0,1밖에 읽지 못한다. 0,1로 구성된 명령어 셋을 기계어라고 한다. 프로그래밍할 때는 거의 사용하지 않음...
	* 어셈블리 언어: 0,1로 구성된 명령어 셋을 인간이 이해할 수 있는 키워드와 매핑시킨 아주 아주 저수준의 언어. 애도 거의 사용하지 않음.
	* 하이 레벨 언어: 현대에서 사용되는 거의 모든 언어를 일컬음.
	* 컴파일러: 하이레벨 언어를 기계어로 이루어진 실행 파일로 바꿔주는 프로그램.
	* 실행 파일은 CPU에 올라가서 실행된다.
	* 인터프리터: CPU가 스크립트 코드를 한줄 한줄 읽어서 실행하는 프로그램
	* 이식성: 여러 OS에 동작하는 속성?
		* C/C++/Go/Rust로 쓰여진 코드: 각 OS에 맞는 컴파일러가 각 OS에 맞는 실행 파일 생성
		* 자바/C#: 컴파일러가 바이트 코드로 변경, 각 OS에 맞는 Virtual Machine이 바이트 코드를 읽어 실행
		* 인터프리터: 각 OS에 맞는 인터프리터가 스크립트 언어를 한 줄 한 줄 읽어서 실행
## C/C++ 언어 소개
* C: 데니스  리치가 만든 프로그래밍 언어
* C++: 비아네 스트로프가 C언어에 OOP / template 개념을 추가한 프로그래밍 언어
* C/C++언어의 설계 철학: 프로그래머를 믿어라
	* 실제 세꼐에서 쓸모가 있어야 한다
	* 프로그래머가 스스로 스타일을 선택할 수 있어야 한다
	* 유용한 기능을 추가하는 것이 오용보다 더 중요하다
	* 프로그래머의 의도를 알 수 없다면 스스로 명시하게 한다
	* C++ 아래에 다른 언어는 없다.

## Learn
xmake 관련 프로젝트 세팅 및 빌드하는 법
```bash
# 프로젝트 생성
$ xmake create hongjungmo-cpp/

# 프로젝트 루트 이동
$ cd hongjungmo-cpp

# 디렉토리 구조
$ tree .
.
├── src
│   └── main.cpp
└── xmake.lua

# 프로젝트 빌드
$ xmake build

$ tree .
.
├── build # <- 여기 추가
│   └── linux
│       └── arm64
│           └── release
│               └── hongjungmo-cpp
├── src
│   └── main.cpp
└── xmake.lua

# 프로젝트 실행
$ xmake run
[ 23%]: cache compiling.release src/main.cpp # <- 컴파일
[ 47%]: linking.release hongjungmo-cpp/ # <- 링킹
hello world! # <- 실행 결과
```
