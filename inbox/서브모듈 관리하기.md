# Git 서브모듈 초기화·브랜치 정렬·신규 추가

## 요약

`.gitmodules`를 기준으로 서브모듈을 일괄 초기화하고, detached HEAD 대신 추적 브랜치로 정렬하는 방법과 원격 기본 브랜치를 확인해 새 서브모듈을 등록하는 절차.

## 내용

### 1. 서브모듈 일괄 초기화 및 동기화

`.gitmodules`의 URL 변경 사항을 동기화하고 중첩 서브모듈까지 한 번에 받아온다.

```bash
git submodule sync --recursive
git submodule update --init --recursive
```

### 2. `.gitmodules`에 지정된 추적 브랜치로 일괄 체크아웃

`git submodule update` 직후에는 각 서브모듈이 gitlink 커밋을 가리키는 detached HEAD 상태가 된다. `.gitmodules`의 `branch` 값과 `origin/<branch>`가 가리키는 커밋이 같음을 확인한 뒤 아래 명령으로 추적 브랜치에 맞춘다.

```bash
git submodule foreach '
  branch=$(git config -f $toplevel/.gitmodules submodule.$name.branch)
  git checkout -B "$branch" "origin/$branch"
'
```

### 3. 새 서브모듈 추가 시 원격 기본 브랜치 확인

원격 저장소마다 기본 브랜치가 `main` 또는 `master`로 다를 수 있으므로 추가 전에 먼저 확인한다.

```bash
git ls-remote --symref https://github.com/<owner>/<repo>.git HEAD
```

확인한 기본 브랜치를 `-b` 옵션으로 명시해 등록한다.

```bash
git submodule add -b <branch> https://github.com/<owner>/<repo>.git <path>
```
